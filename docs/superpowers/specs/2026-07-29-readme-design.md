# README Tablo: спецификация

## Цель

Заменить устаревший README на англоязычное описание расширения Tablo для пользователя и разработчика.

## Содержание

README содержит:

1. Краткое назначение: Tablo заменяет страницу новой вкладки Chrome и организует закладки.
2. Список пользовательских возможностей, подтверждённых кодом проекта: пространства, папки и ссылки, поиск, перетаскивание, открытые вкладки и недавняя история, темы, импорт и экспорт, локальное хранение.
3. Установку и запуск: `npm install`, `npm run watch`, выбор папки `dist` через `chrome://extensions` → «Load unpacked».
4. Production-сборку: `npm run build` и выбор папки `dist`.
5. Таблицу основных npm-команд: `watch`, `watch2`, `build`, `typecheck`, `test`, `clean`.

## Ограничения

- README написан на английском языке.
- Не описывает устаревшую сетевую синхронизацию и структуру прежнего проекта TMex.
- Не добавляет команды или возможности, отсутствующие в текущем проекте.
