# Удаление группы закладок

## Поведение

1. В контекстное меню заголовка группы добавить действие `Delete group`.
2. Нажатие открывает подтверждение удаления.
3. При подтверждении группа удаляется, а её закладки становятся обычными
   закладками той же папки.
4. Перенесённые закладки добавляются после всех текущих элементов папки.
5. Порядок закладок внутри удаляемой группы сохраняется.
6. При отмене подтверждения состояние не меняется.
7. Удаление группы и перенос её закладок образуют одну операцию store, поэтому
   доступны через существующий Undo.

## Реализация

- В `dashboard/domain.ts` добавить чистую операцию удаления группы по `groupId`:
  она найдёт родительскую папку, удалит group-элемент и добавит его `groupItems`
  в конец `folder.items`, присвоив новые fractional positions.
- В `dashboardStore.ts` добавить action, оборачивающий доменную операцию через
  `applyWithUndo`.
- В `FolderGroup.tsx` добавить пункт меню и использовать существующий механизм
  подтверждения удаления, после которого вызвать action store.

## Проверка

- Доменный тест: группа исчезает, её закладки находятся в конце папки в прежнем
  порядке и имеют обычный тип bookmark.
- Store-тест: Undo восстанавливает исходную группу и её закладки.
- Контрактный тест компонента: меню содержит действие удаления.
