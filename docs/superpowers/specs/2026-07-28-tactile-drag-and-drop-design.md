# Тактильное перетаскивание закладок и групп

## Цель

Сделать перетаскивание закладок и групп наглядным: источник исчезает из
списка, а в точке вставки сразу отображается полупрозрачная копия
перетаскиваемого содержимого.

## Поведение

1. После преодоления порога drag исходная закладка, несколько выбранных
   закладок или целая группа временно исключаются из раскладки через
   `display: none`.
2. Соседние элементы в источнике занимают освободившееся место без
   дополнительного placeholder.
3. При наведении на допустимую точку вставки в её контейнер вставляется
   временный preview:
   - для закладки — копия её внешней обёртки;
   - для группы — копия всего блока группы;
   - для нескольких закладок — копии всех элементов в исходном порядке.
4. Preview участвует в нормальной раскладке контейнера и раздвигает соседние
   элементы. Его содержимое и фон отображаются с прозрачностью 18%.
5. При переходе в другую точку вставки старый preview удаляется до вставки
   нового.
6. Плавающая копия под курсором остаётся визуальным индикатором захвата, но
   фон выбранной закладки в ней получает прозрачность 18% вместо плотного
   фона выделения.
7. При отмене или завершении drag удаляются preview и временное скрытие
   источника. Сохранение данных выполняется только существующим `onDrop`.

## Реализация

- В `dragAndDrop.ts` добавить небольшие DOM-хелперы для определения внешнего
  layout-элемента источника, создания preview-клонов и их очистки.
- В `processItemDragAndDrop.ts` при старте drag скрывать layout-элементы,
  пересчитывать зоны drop и заменять линейный placeholder на preview-клоны в
  целевом контейнере.
- В `processFolderDragAndDrop.ts` аналогично скрывать блок группы и вставлять
  preview группы в целевую позицию вместо вертикальной линии.
- В `dragAndDrop.scss` задать стили preview и переопределение фона клонов под
  курсором. Стили не должны перехватывать события указателя.
- Существующие тонкие `bm-item-placeholder` и `bm-folder-placeholder` больше
  не используются для закладок и групп.

## Ограничения

- Изменение затрагивает только временную DOM-визуализацию; структура данных,
  правила расчёта позиции и обработчики `onDrop` остаются прежними.
- Preview помечается `data-dad-preview="true"`; расчёт `itemRects` и
  `getItemIdByIndex` игнорируют такие узлы, поэтому preview не влияет на
  итоговый `insertBeforeItemId`.
- Поведение для сортировки пространств не меняется.

## Проверка

1. Unit-тесты DOM-хелперов: скрытие/восстановление источника, создание preview
   для закладки, нескольких закладок и группы, очистка preview.
2. Контрактные тесты стилей: preview имеет прозрачность 18%, а плавающий клон
   не использует плотный фон выделения.
3. Ручная проверка: источник схлопывается, preview раздвигает элементы в
   целевой позиции, отмена возвращает исходную раскладку, drop перемещает
   данные в ожидаемую позицию.
