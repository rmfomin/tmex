# Надёжный перенос папок

## Цель

Убрать непрерывные сдвиги списка папок во время drag-and-drop и сделать итоговую позицию предсказуемой.

## Поведение

1. После прохождения порога drag исходная папка скрывается из списка. Остальные папки один раз занимают освободившееся место.
2. За указателем движется полупрозрачная копия папки без содержимого.
3. Предполагаемая позиция показывается индикатором на границе целевой папки. Индикатор не участвует в раскладке и не сдвигает папки.
4. Индикатор определяется по половине ширины папки: левая половина означает вставку перед папкой, правая — после неё.
5. При смене пространства индикатор скрывается; после отрисовки нового пространства координаты целей пересчитываются.
6. При отпускании кнопки папка перемещается в отмеченную позицию. При отпускании вне цели или отмене перенос отменяется и исходная папка возвращается.

## Техническое решение

- Скрывать источник существующей функцией `setDragSourceHidden`.
- После скрытия источника пересчитывать зоны drop без исходной папки, чтобы координаты соответствовали видимому списку.
- Вместо `createDropPreview` и вставки клона в контейнер использовать один `position: fixed` индикатор в `document.body`.
- Удалять индикатор при отмене, drop и переходе на пространство.

## Ограничения

- Изменение распространяется только на перенос папок.
- Порядок в хранилище меняется только в обработчике `onDrop`.
- Не добавлять зависимости.

## Проверки

- После начала drag источник скрыт, а зоны папок пересчитаны без него.
- При перемещении над папкой отображается индикатор и не создаётся полноразмерное превью в раскладке.
- При завершении или отмене индикатор удаляется, а источник восстанавливается при отмене.
