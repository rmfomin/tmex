# Выделение закладок рамкой

## Цель

Добавить выделение области ЛКМ для последующего группового переноса закладок и групп.

## Взаимодействие

1. Пользователь зажимает ЛКМ на пустом месте списка закладок.
2. Поверх списка появляется полупрозрачная рамка. При перемещении курсора её размеры меняются.
3. Во время перемещения вычисляется черновой выбор элементов, пересекающихся с рамкой.
4. После отпускания ЛКМ выбор сохраняется и подсвечивается.
5. Пользователь перетаскивает любую выбранную закладку или заголовок выбранной группы. Переносятся все выбранные сущности.

## Нормализация выбора

- Закладки верхнего уровня папки выбираются по отдельности.
- Пересечение рамки с заголовком группы выбирает всю группу.
- Одна или несколько закладок только из одной группы выбираются по отдельности, если рамка не пересекла заголовок группы.
- Если рамка пересекла закладки разных групп, каждая группа выбирается целиком.
- Если рамка пересекла верхнеуровневую закладку и закладку группы, выбираются закладка и группа целиком.
- Учитываются только отображаемые элементы текущего состояния интерфейса: свёрнутые, скрытые фильтром или архивные элементы вне отображения не попадают в выбор.

## Перетаскивание

- Выбор только из закладок можно переносить в папку или в группу.
- Если в выборе есть хотя бы одна группа, перенос разрешён только в папку.
- Недопустимые group-drop-зоны для такого выбора не подсвечиваются и не принимают drop.
- По завершении или отмене переноса выбор сбрасывается.

## Сброс выбора

Выбор сбрасывается при клике по пустой области, смене пространства, изменении поиска или фильтров, а также после завершения либо отмены перетаскивания.

## Архитектура

- В UI store хранятся идентификаторы выбранных переносимых элементов: закладок и групп.
- Отдельный модуль вычисляет пересечение прямоугольников и нормализует видимые DOM-элементы до корневых сущностей.
- Компонент списка отображает рамку выделения и передаёт рассчитанный выбор в UI store.
- Drag-and-drop получает корневой выбор из store, а не из глобального массива DOM-элементов.
- Существующий `moveFolderItems` используется без изменения контракта: group уже является перемещаемым `ItemV3`.

## Проверки

- Геометрия пересечения рамки и элемента.
- Нормализация: закладки папки, закладки одной группы, две группы, смешанный выбор, заголовок группы.
- Ограничение drop в группу при наличии group в выборе.
- Перенос нескольких закладок и смешанного выбора в папку.
- Сброс выбора в обозначенных сценариях.
