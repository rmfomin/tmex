# Separate Folder and Group Chevrons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Разделить шевроны папки и группы и сделать цвет шеврона папки неизменным между темами.

**Architecture:** `Folder` и `FolderGroup` получают собственные SVG-файлы. Цвет шеврона папки зашит в SVG, а шеврон группы продолжает использовать существующую CSS-переменную темы.

**Tech Stack:** React, TypeScript, SCSS Modules, Jest.

## Global Constraints

- Размер SVG и анимация поворота шевронов не меняются.
- Цвет шеврона папки: `#242424` в обеих темах.
- Цвет шеврона группы: `var(--icon-color-group-chevron)`.
- Не добавлять файлы в staging area и не создавать коммит без отдельного разрешения пользователя.
